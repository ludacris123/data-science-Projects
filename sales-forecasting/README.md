# Sales Forecasting

A compact time-series project that creates realistic daily sales data, engineers calendar and lag features, and forecasts the next 30 days.

## Skills demonstrated

- Time-series feature engineering
- Lag and rolling-window features
- Chronological train/test splitting
- Random forest regression
- MAE, RMSE, and MAPE evaluation
- Recursive multi-step forecasting

## Run

```bash
pip install pandas numpy scikit-learn matplotlib
python forecast.py
```

Outputs include the synthetic sales history, evaluation metrics, future forecast CSV, and forecast chart.
