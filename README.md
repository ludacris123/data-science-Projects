## How to Explore

1. Clone the repository:

```bash
git clone https://github.com/ludacris123/data-science-Projects.git
cd data-science-Projects
```

2. Create and activate a virtual environment.
3. Install the dependencies required by the notebook you want to run.
4. Open the project in Jupyter Notebook or VS Code and run the cells in order.

> Individual folders and notebooks may use different datasets and dependencies. Check each project before running it.
