# Data Science Projects

A practical collection of data science and machine-learning work by **Rishabh Patel**.  
This repository documents my progress from data exploration and visualization to predictive modelling and AI applications.

## Featured Projects

| Project | What it demonstrates | Key outputs |
|---|---|---|
| [Customer Churn Prediction](./customer-churn-prediction) | Classification pipelines, cross-validation, model comparison and ROC-AUC evaluation | Saved model, metrics, predictions and diagnostic charts |
| [Sales Forecasting](./sales-forecasting) | Time-series features, chronological validation and recursive forecasting | 30-day forecast, evaluation metrics and forecast chart |
| [Customer Segmentation](./customer-segmentation) | K-Means, silhouette analysis, PCA and business personas | Customer assignments, segment profiles and PCA chart |

Each featured project generates its own realistic dataset, so it can run immediately without downloading external data.

## Focus Areas

- Data cleaning and exploratory data analysis
- Statistical analysis and visualization
- Feature engineering and model preparation
- Supervised and unsupervised machine learning
- Model evaluation and performance improvement
- Reproducible Python workflows

## Quick Start

```bash
git clone https://github.com/ludacris123/data-science-Projects.git
cd data-science-Projects
```

Open a featured project, install the packages listed in its README, and run the Python script. Generated models, metrics, tables and charts are written to that project's `outputs/` directory.
