# Customer Segmentation

An unsupervised-learning project that groups retail customers by spending behaviour and identifies useful marketing personas.

## Skills demonstrated

- Data preparation and scaling
- K-Means clustering
- Silhouette-score model selection
- PCA visualization
- Cluster profiling and persona generation
- Exportable customer assignments

## Run

```bash
pip install pandas numpy scikit-learn matplotlib
python segment.py
```

The script creates cluster assignments, a segment summary, model-selection scores, and a two-dimensional PCA chart.
